# fitting

> **이 일은 어느 세션의 것인가** — 일의 주인을 정하고, 바꾸고, 정할 수 없으면 올리고, 끝나면 돌려준다.

상태: **뒤에 만든다 — 아직 만든 것이 없다.** 설치할 수 없고 모음 목록에도 올라 있지 않다. 이 문서는 이 플러그인이 맡을 것과 맡지 않을 것을 미리 적어 두는 자리다. `casting` 다음에 만든다.

## 맡는 것

- **배정** — 새 일이 누구에게 가나. 범위에 맞으면 그 주인에게, 여러 범위에 걸치면 쪼개서 각 주인에게, 주인이 없으면 위로.
- **받은 일** — 주인이 받은 일을 적어 두고, 열린 것이 남았는지와 자리가 비었는데 받을 일이 남았는지를 본다.
- **넘김** — 내 범위가 아닌 일을 맞는 주인에게 넘기고, 받는 쪽이 열거나 버릴 때까지 따라간다.
- **결정 요청** — 내가 정할 수 없는 것을 정할 세션에게 올리고 답을 기다린다. 누가 무엇을 정하는지(결정권)를 여기서 읽는다.
- **돌려주기** — 끝난 결과를 맡긴 쪽에 돌려준다.
- **보고** — 주인이 자기 일의 상태를 알리고, 위가 직접 확인해 적는다.

## 맡지 않는 것

| 무엇 | 맡는 곳 |
| --- | --- |
| 어떤 세션들이 있고 누가 누구 아래인가(세션 잡아 두기·콜시트·자리 지킴) | `casting` |
| 일 하나를 어떻게 하나(단계·기록·합치기) | `tailoring` |
| 말이 세션 사이에 닿게 하는 통로, 다른 기계에서 돌리기, 토큰 | 이 모음의 다른 플러그인(아직 없음) |

`fitting`은 `casting`의 콜시트를 읽는다(누가 있고, 무엇을 맡고, 누구 아래인가). `casting`은 `fitting`을 모른다.

## 스킬(안)

스킬 이름은 만들 때 다시 정한다.

| 스킬 | 누가 부르나 | 하는 일 |
| --- | --- | --- |
| `dispatch` | 일을 보내는 세션 | 주인을 정해 보내기 — 배정·넘김·결정 요청 |
| `debrief` | 일을 마친 세션 | 끝난 것을 돌려주고 알리기 |
