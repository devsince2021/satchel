# casting

> **어떤 세션들이 있고 누가 누구 아래인가** — 세션을 세우고, 스스로 명부에 올리게 하고, 누가 자리에 있는지 안다.

상태: **설계 중 — 아직 만든 것이 없다.** 설치할 수 없고 모음 목록에도 올라 있지 않다. 이 문서는 이 플러그인이 맡을 것과 맡지 않을 것을 미리 적어 두는 자리다.

## 맡는 것

- **잡아 두기** — 위에 있는 세션이 아래 리드의 작업 자리(브랜치·워크트리)와 세션을 잡아 두고, 콜시트에 그 줄을 "잡아 둠"으로 적는다.
- **도착하기** — 띄워진 세션이 첫 일로 자기 세팅을 하고, 실제 자리를 확인해 콜시트 줄을 "도착함"으로 바꾼 뒤 위에 알린다. 손으로 띄운 세션도 같은 길로 콜시트에 오른다.
- **콜시트(callsheet)** — 세션 명부. 세션마다 줄 하나: 이름, 맡은 범위(적기만 한다), 상급자(없으면 꼭대기), 상태, 도는 자리. 꼭대기는 "상급자가 나"인 줄을 읽어 자기 아래를 안다.
- **자리 지킴** — 누가 지금 자리에 있는지(오래 갱신이 없으면 "자리에 없음"), 오래 떠 있는 리드 세션이 일을 놓고 서 있지 않게 하는 턴 끝 조건.
- **내리기** — 세션이 콜시트에서 내려오거나 위가 닫는다.

## 맡지 않는 것

| 무엇 | 맡는 곳 |
| --- | --- |
| 일 하나를 어떻게 하나(단계·기록·합치기) | `tailoring` |
| 이 일은 어느 세션의 것인가(배정·넘김·결정 요청·돌려주기·보고) | `fitting` |
| 말이 세션 사이에 닿게 하는 통로, 다른 기계에서 돌리기, 토큰 | 이 모음의 다른 플러그인(아직 없음) |

"맡은 범위"는 콜시트 줄에 적어 두기만 한다. 그 범위를 읽어 일을 누구에게 보낼지 정하는 것은 `fitting`의 일이다.

## 스킬(안)

| 스킬 | 누가 부르나 | 하는 일 |
| --- | --- | --- |
| `book` | 위에 있는 세션 | 아래 리드의 자리와 세션을 잡아 둔다 — 콜시트 줄 "잡아 둠" |
| `checkin` | 띄워진 세션(또는 손으로 띄운 세션) | 스스로 세팅하고 도착을 알린다 — 콜시트 줄 "도착함" |
