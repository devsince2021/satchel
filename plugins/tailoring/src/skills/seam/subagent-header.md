# 하위 에이전트 공용 머리말 (seam)

seam 작업 세션이 하위 에이전트(리뷰어·조사·시험 초안)를 띄울 때 지시 맨 위에 아래 블록을 그대로 붙이고 자리표를 채운다. 리뷰어는 `model: <그 값>`으로 띄운다 — 그 값은 시작 지시·단계 안내가 적은 리뷰어 모델(설정 `session.model`, 작업 세션과 같은 모델)이고, 빼면 다른 모델로 뜬다. 작업 세션의 PreToolUse 훅이 하위 에이전트 프롬프트가 이 블록 첫 줄로 시작하는지(또는 "먼저 `<이 파일 경로>`를 읽고 따르라" 줄이 있는지), 자리표(`{…}`)가 남지 않았는지 보고 어긋나면 띄우지 않는다.

```
[공용 머리말 — seam]
- 먼저 읽는다(지금 일에 걸리는 절만): ① 지시가 준 파일 ② {GUIDE_DOCS}(규칙 색인·사용자 결정 패턴) → 걸리는 규칙 문서는 머리와 용어 정의부터. 규칙과 지시가 부딪히면 보고에 적는다.
- 자리: {WORKTREE} 안의 {SCOPE}만. 그 밖은 읽기만.
- 검사: 프로젝트의 무거운 검사(합치기 전 검사 등)를 돌리지 않는다. 오래 걸리거나 출력이 긴 명령은 출력을 파일로 돌리고 끝만 본다.
- 편집: Edit·Write만. Bash에 `cd … &&`를 묶지 않는다 — 절대 경로·`git -C <dir>`. 여러 단계 셸은 {SCRATCHPAD}에 스크립트로.
- 경로에 glob(`*`·`?`·`[`)과 그 뒤 `..`을 함께 쓰지 않는다 — 확인 창에 멈춘다. find로 찾은 경로를 그대로 쓴다.
- 셸 매개변수 가공(`${x%…}`·`${x#…}`·`${x/…}`·`$x:h` 꼴)을 쓰지 않는다 — 훅이 막는다. 그런 셸은 스크립트 파일로.
- git: 커밋·push·merge·reset·stash·clean 금지. 하위 에이전트를 다시 띄우지 않는다. 사용자에게 묻지 않는다(질문 창은 막힌다).
- 막힌 명령을 스크립트·인터프리터로 돌아가지 않는다 — 막히면 그대로 보고에 적는다.
- 판정에 쓰는 숫자는 명령으로 재고 명령을 함께 적는다.
- 끝: 최종 보고 전문을 {REPORT}에 쓰고, 답에는 판정과 Critical·Important 수만.
```

자리표: `{WORKTREE}`(작업 워크트리 꼭대기)·`{SCOPE}`(읽기만이면 "없음(읽기만)")·`{SCRATCHPAD}`·`{REPORT}`(`<작업 워크트리>/<설정 seam.pieces>/<작업 ID>-<슬러그>/agents/<이름>.md`)·`{GUIDE_DOCS}`(설정 `seam.guide_docs` 가운데 있는 파일). 리뷰어 지시 본문에는 "이 일은 읽기만 한다(편집·커밋·무거운 검사 금지 — 머리말 끝 줄의 보고 파일 하나만 쓴다)"를 더한다. 시험 초안 지시는 `{SCOPE}`를 쓸 시험 파일 자리로 채우고 "시험 파일만 쓴다 — 돌리기·빨강 확인·커밋·판정은 세션이 한다"를 더한다(seam ③).
