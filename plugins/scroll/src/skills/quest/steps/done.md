# ⑥ 마무리

## 할 일

1. 끝 검증: 바뀐 시험, 늘 `python3 "${CLAUDE_PLUGIN_ROOT}/src/scripts/quest/main.py" carryover`, 코드·빌드 파일이 바뀌었으면 가벼운 표적 검사. 무거운 판정(설정 `deliver.verify`)은 리드가 합칠 때 돈다. 돌리지 않은 무거운 검사는 `retro.md` `## 넘길 일` 항목으로 남긴다(장부 번호는 리드가 합칠 때 매긴다). `retro.md` `## 끝 검증`에 `- <명령> → <결과>`. 코드 뒤 검토 중에 쓴 줄은 리뷰 반영에서 고친 것이 있으면 다시 돌려 고친다.
2. 닫을 장부 줄: `<장부>` 파일은 고치지 않는다(세션 deny — 리드가 합칠 때 옮겨 적는다). 상태가 `요구사항 <ID>`인 `<장부>` 줄마다 `retro.md` `## 닫을 장부 줄`에 한 줄 `- <장부 ID>: <상태> — <근거>` — 상태는 `끝`(근거: 커밋·결정·시험)·`버림`(근거: 까닭)·`넘김`(근거: 보낸 증거 — `msg <16진 8자+>` 또는 날짜·시각과 받는 쪽 주소, 주소 낱말은 고정 `SendMessage`)·`열림`(근거: `<ID> 넘김 — <까닭>` — 회고 넘길 일에는 다시 적지 않는다) 가운데 하나. 걸린 줄이 없으면 `- 없음`.
3. 짧은 회고(기존 장부 줄은 2에서 적었으니 넘길 일에는 새 일만): `## 어긋난 것`(계획·요구와 다르게 간 것), `## 바뀐 규칙 문장`("바뀐 규칙 문장" 확인이 켜져 있을 때만 — 설정 `quest.rule_docs`에 `patterns`가 있을 때, 틀의 주석 자리에. 작업 범위에서 규칙 문서(그 `patterns`에 맞는 파일)를 바꿨으면 이 절을 두고 파일마다 바꾼 문장을 한 줄씩 적는다 — 옛 → 새, 옛·새 문장은 `` `…` `` 안에, 바꾼 것이 없으면 `- 없음`. 파일마다 줄이 있어야 끝 확인 `end`가 통과한다), `## 넘길 일` — 항목마다 한 줄 `- <받는 쪽>: <내용>`(번호·장부 줄 없이, 하위 항목 없이, 받는 쪽은 `:`·`` ` ``·`|` 없이 20자 안), 없으면 `- 없음`. 번호는 리드가 합칠 때 매긴다.
4. 작업 목록 줄은 고치지 않는다(리드가 합칠 때 `끝`으로). 커밋 `<ID> done: …`.
5. `python3 "${CLAUDE_PLUGIN_ROOT}/src/scripts/quest/main.py" end <ID>` → `quest_check: 통과`(막히면 고치고 `<ID> done: …`로 다시). 브랜치는 그대로 둔다(합치기는 리드). 리드에게 `[<ID> → <리드>] 끝: <작업 폴더>/retro.md`(SendMessage).

## 쓰는 틀

- `${CLAUDE_PLUGIN_ROOT}/src/skills/quest/templates/retro.md` → `<작업 폴더>/retro.md`.

## 지킬 것

- 끝 확인(`end`)이 막는 것: 기록 파일 넷과 절, 요구사항 틀 칸, 커밋 차례(단계 사슬·할 일 시험 차례), 반영 표, 넘길 일 꼴, `## 닫을 장부 줄`과 장부 대조(빠진 줄·장부에 없는 줄·이 작업 줄이 아닌 줄·꼴이나 근거가 틀린 줄, 작업 범위에서 `<장부>`가 바뀜), 켰으면 바뀐 규칙 문서마다 회고 줄.

## 마치는 조건

- `end <ID>`가 `quest_check: 통과`이고 리드에게 끝을 알렸다.

## 커밋
